## 3. reflog

_Пояснення:_ У reflog збережено початковий хеш комміту та новий хеш, утворений після виконання git commit --amend.

## 4. revert

_Пояснення:_ Замість небезпечного стирання історії (reset) скасування відбулося через новий відмовляючий комміт revert.
